# 资料口径

全部主体和观测均为本地合成资料，不代表企业、个人或真实设备。编号只在资料包内有意义，金额为人民币元，时刻统一为带 +08:00 的北京时间。空单元表示未知或不适用，不等于零；真假值用 true/false；数值不含千位分隔。CSV 行顺序不表示业务先后。时间区间采用左闭右开，除非字段说明另有规定。

weekly 的 planned_wet_t 是计划量；actual_wet_t 为空表示没有执行观测，0 是计划后零到货。热值以干基每吨兆焦给出，含水率为质量百分数，损耗由 storage 逐周年龄段给出，不设隐含转换系数。情景中共同天气不是独立供应商事件。合同 min_t 是不可撤销保底量，option_t 仅为可选上限；confirmed_t 已履行，不能再次购买或撤销。路线容量与加工能力按周共享。forecast_issue 的预测只可使用 available_at 不晚于该时点的资料。
前104周是周索引0至103的历史窗口，104至115是本轮承诺期；周0从2025-01-06开始。route_capacity 在承诺期给的是事先可知额定能力，不是未来已发生的道路状况。历史库存没有逐周真值，本轮由 opening_stock 起算；超过 storage 最后年龄段的原料按最后段损耗继续处理。保底量以合作社为单位，需要结合地块的采收资格而非指定某一地块保证兑现。每个方案的 declared forecast_issue 是承诺评审时点，不能把未来实际路线当事先已知。
本轮完整承诺期为周104至155，共52周；104至115只是最初的12周交接段。额定路线在全部承诺期预登记。800湿吨是统一库容；季节库存能桥接采收期但不得凭空生成。方案中签约状态只有实际 signed 不可撤回，proposal 仍可变。

## sources
地块采收与合作社关系。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| source_id | string | 来源地块 |
| coop_id | string | 合作社 |
| region | string | 共同天气区 |
| harvest_months | string | 允许月份分号分隔 |
| rotation_weeks | integer | 最小采收间隔 |
| last_harvest_week | integer | 最近采收周 |
| dry_mj_per_t | number | 干基热值 |

记录键：source_id。

## weekly
两年的计划及执行观测。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| record_id | string | 记录 |
| week | integer | 周 |
| source_id | string | 地块 |
| planned_wet_t | number | 计划湿吨 |
| actual_wet_t | number | 实际湿吨 |
| moisture_pct | number | 含水率 |
| weather | string | 区域天气 |
| available_at | datetime | 可知时刻 |

记录键：record_id。

## route_capacity
按周的共享运输能力。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| record_id | string | 记录 |
| week | integer | 周 |
| route_id | string | 通道 |
| capacity_t | number | 湿吨容量 |
| available_at | datetime | 可知时刻 |

记录键：record_id。

## coop_routes
normal 与 backup 分别为正常和替补；同名通道共享容量。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| coop_id | string | 合作社 |
| normal | string | 正常通道 |
| backup | string | 替补通道 |
| processing_t | number | 周加工能力 |

记录键：coop_id。

## storage
损耗为该年龄周发生的质量损失比例，容量是所有年龄共同上限。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| age_week | integer | 入库年龄周 |
| loss_fraction | number | 该周质量损失率 |
| capacity_t | number | 共同仓容 |

记录键：age_week。

## contracts
面向未来12周的候选及已签承诺。scenario 同值构成一套方案。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| contract_id | string | 合同 |
| scenario | string | 方案 |
| coop_id | string | 合作社 |
| week | integer | 交付周 |
| min_t | number | 保底湿吨 |
| option_t | number | 可选湿吨 |
| confirmed_t | number | 已履行量 |
| price_yuan_t | number | 每湿吨价格 |
| status | string | signed或proposal |

记录键：contract_id。

## demand
连续供汽热量需求与缺供风险界限。连续缺供为相邻周低于需求，emergency_cost 是每兆焦煤替补成本。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| week | integer | 周 |
| heat_mj | number | 需求兆焦 |
| risk_limit | number | 可接受缺供概率 |
| emergency_cost | number | 应急单价 |

记录键：week。

## new_information
签约后更新，只影响可知时点以后的分析。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| notice_id | string | 通知 |
| week | integer | 影响周 |
| route_id | string | 通道 |
| capacity_t | number | 新容量 |
| available_at | datetime | 可知时刻 |

记录键：notice_id。

## opening_stock
签约截止时真实在库原料，按原来源及年龄保留。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| stock_id | string | 在库记录 |
| source_id | string | 来源 |
| age_week | integer | 入库年龄 |
| wet_t | number | 湿吨 |
| moisture_pct | number | 当前含水率 |
| as_of | datetime | 盘点时刻 |

记录键：stock_id。
